# AllTools Product Truth

AllTools is an offline-first desktop utility platform for people who regularly handle PDFs, images, and documents. Its core promise is practical local processing without cloud uploads. The MVP is Electron + TypeScript on the desktop side with on-demand, approved Python plugins managed separately.

The primary operating scene is a focused desktop work session: a user opens a tool, chooses one or more files, sees what will happen, runs one action, and downloads the outputs. The interface must make that sequence obvious before adding personality.

The current MVP includes a PDF-to-text tool that accepts multiple PDFs, extracts one TXT result per input, shows progress, and supports individual and batch downloads. The application should preserve these capabilities while the visual system changes.

The product should feel authored, calm, tactile, and private—not like a generic AI dashboard, SaaS landing page, or admin panel. The UI must avoid filler claims and invented feature content. Every visual element should support discovery, confidence, or the file task itself.
