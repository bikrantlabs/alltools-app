# Reference Direction: ZCode + Atomic

## ZCode observations

The ZCode reference frames a focused development workspace around long-running tasks, explicit goals, and clear capability grouping. Its product language favors a dark, high-contrast environment with a strong central workspace and a sense of continuous work rather than a marketing-card grid. The useful translation for AllTools is a calmer workbench with a clear current context, grouped tool collections, and a main action surface that does not compete with the navigation.

Source: https://zcode.z.ai/en

## Atomic observations

Atomic presents local/private computing as a primary product identity. The useful translation for AllTools is the combination of dark product surfaces, strong local-first messaging, compact app-like organization, and the separation of contexts into clear groups. Its hierarchy is more useful as a workspace model than as a page full of promotional copy.

Source: https://atomic.chat/

## AllTools synthesis

The redesign should be dark-first but support a persistent light/dark theme switcher. The catalog should become a workspace index: a compact sidebar for collections, a top context bar, a featured “continue working” or installed-tool area, and a clearly separated catalog area for available plugins. The PDF page should use the same workspace shell and make the current tool, route, local status, queue, processing state, and output state visible without large empty regions.

Avoid copying either site literally. Borrow the useful structural ideas: dark focus, local ownership, grouped contexts, clear task progression, and a surface hierarchy that feels like an application rather than a landing page.
